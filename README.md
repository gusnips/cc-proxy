# cc-proxy

Claude Code, powered by **OpenAI Codex**, **Kimi**, **Grok**, **OpenCode Go**,
**GitHub Copilot**, or **Cursor Agent**.

> Originally forked from
> [raine/claude-code-proxy](https://github.com/raine/claude-code-proxy).
> An existing `claude-code-proxy` config is read as a fallback.

Docs: <https://github.com/gusnips/cc-proxy/tree/main/docs/src/content/docs>
(run `just docs` to serve them locally)

LLM docs: build with `just docs` (llms.txt is generated by the docs site).

## Why?

Claude Code remains an excellent coding harness, with strong tools, skills,
hooks, subagents, and editor integrations. cc-proxy keeps that client
experience while translating its Anthropic API traffic for subscription-backed
provider services.

One local process handles provider authentication, model-based routing,
protocol translation, streaming responses, and diagnostics. The built-in
monitor lets you choose providers and saved accounts, check usage and manage
rotation. Its Activity tab keeps the request, error and throughput details.

## Quick start with Codex

Install on macOS or Linux:

Install with Homebrew:

```sh
brew install gusnips/cc-proxy/cc-proxy
```

Or install from a GitHub release:

```sh
curl -fsSL https://raw.githubusercontent.com/gusnips/cc-proxy/main/scripts/install.sh | bash
```

Or install from a local checkout:

```sh
./scripts/install.sh --local
```

Windows and other prebuilt artifacts are available from
[GitHub Releases](https://github.com/gusnips/cc-proxy/releases).

Sign in with a **ChatGPT Plus or Pro account**, not an OpenAI API account:

```sh
cc-proxy login codex
```

Start the proxy and send Claude Code through it:

```sh
cc-proxy start
cc-proxy status
```

`start` runs the proxy in the background and turns routing on. If you are
signed in to more than one provider, it asks which one Claude Code should
use. If you aren't signed in to any, it asks which one to sign in to.

Open `cc-proxy monitor` from any terminal. Accounts opens first: use the arrows
and Enter to choose a provider or saved login. Press `2` for live activity.
Closing the monitor leaves the proxy running. `cc-proxy restart` restarts it;
`cc-proxy reload` asks it to read config changes.

Sign in to the other providers the same way (`kimi`, `grok`, `cursor`,
`glm`, `opencode`, `copilot`, `antigravity`), then check state and usage:

```sh
cc-proxy login kimi
cc-proxy auth status kimi
cc-proxy usage
cc-proxy models list
```

`cc-proxy login codex` is the short form of `cc-proxy auth login codex`.
Sign out with `cc-proxy logout codex` (or `cc-proxy auth logout codex`).
Both forms take the same options.

`cc-proxy usage` shows how much of your Claude, Codex, Kimi and OpenCode Go plans
you have used, and when each limit resets.

Tune the proxy without editing files by hand, and keep it current:

```sh
cc-proxy config list
cc-proxy config set codex.fullLane true
cc-proxy update --check
cc-proxy update
```

Then run `claude` as you always do. Every Claude Code window and terminal goes
through the proxy, including ones that are already open (they follow within a
few seconds) and ones started from an editor.

cc-proxy does this by writing a few lines to the `env` block of
`~/.claude/settings.json`. There is no shell hook, no `cc-proxy claude`
wrapper and nothing to source.

Switch whenever you want:

```sh
cc-proxy use kimi     # send Claude Code to another provider
cc-proxy use claude   # use a saved Claude subscription through the proxy
cc-proxy use direct   # restore Claude Code's login; leave the proxy running
cc-proxy stop         # restore Claude Code's login and stop the proxy
```

Routing never comes back by itself. It starts again only when you run
`cc-proxy start` or `cc-proxy use <provider>`.

Claude Code asks for `opus`, `sonnet`, `haiku` and `fable`. cc-proxy turns each
name into a model of the provider you picked, using what that provider offers
today. While routing is on, its header and `/model` picker show the provider
and model, such as `codex/gpt-6.1-sol`. The native model ID stays unchanged.
See which one each name gets, or choose your own:

```sh
cc-proxy models
cc-proxy models set haiku gpt-6-luna
cc-proxy models choose
```

`cc-proxy models choose` asks about each name in turn, with search, which helps
on providers with hundreds of models. Press Enter to keep a name as it is.

A window that was open before `~/.claude/settings.json` existed can't see the
change until you restart it. See
[Configure Claude Code](docs/src/content/docs/using/configure-claude-code.md)
for the exact lines, what happens to values you set yourself, and the limits.

See [Getting started](docs/src/content/docs/getting-started.md)
for the complete first session.

Optional Codex image generation and editing can reuse the same ChatGPT login:

```sh
CCP_CODEX_IMAGES_API=1 cc-proxy start
curl http://127.0.0.1:18765/v1/images/generations \
  -H 'Content-Type: application/json' \
  -d '{"prompt":"A paper-cut fox","model":"gpt-image-2"}'
```

The opt-in Images API returns base64 image data and consumes the signed-in account's image quota. Image prompts and payloads are excluded from traffic captures. See the [HTTP API](docs/src/content/docs/reference/http-api.md) for generation and edit schemas.

## More than one login

Codex, Kimi, Grok and Antigravity can keep several accounts. Add a second
Codex account, then switch to it:

```sh
cc-proxy auth add codex --name work
cc-proxy auth use codex work
cc-proxy auth status codex
```

`cc-proxy login codex` asks whether to add or replace an account when you're
already signed in. To replace it without the question, use
`cc-proxy login codex --replace`. Sign out of one account with
`cc-proxy logout codex work`, or all of them with `cc-proxy logout codex --all`.

Automatic switching is off by default. Enable it with:

```sh
cc-proxy config set auth.autoRotate true
```

A 429 with a provider-stated retry or reset time makes that account wait.
The proxy tries another saved account from the same provider and keeps using
it. Antigravity switches for spent quota, not temporary capacity throttles.
A model-specific limit does not block other models.

Rotation only applies to Messages requests before output starts, not images,
audio or OpenAI-compatible routes. Codex's encrypted history stays with the
saved login that created it, including after a restart. When a conversation
carries reasoning from another saved login, cc-proxy drops only that reasoning
and continues with the text and tool history. See [rotation limits](docs/src/content/docs/reference/configuration.md#saved-accounts-and-auto-rotate).

Run `cc-proxy usage claude`, `cc-proxy usage codex` or `cc-proxy usage kimi` to see how much is left on
each saved account and when each window resets. The monitor's Accounts tab
shows the same usage and wait timers. Select a row and press Enter to switch
accounts, add a login, change the fallback order or turn auto-rotate on or off.
Request rows in Activity keep the name of the account they actually used.

Run `cc-proxy config` for keyboard settings: Up and Down move, Left and Right
change fixed choices, Enter edits a value. Changes save at once.

## Providers

| Provider       | Account                                | Model selection                                                          |
| -------------- | -------------------------------------- | ------------------------------------------------------------------------ |
| Codex          | ChatGPT Plus or Pro                    | Any `gpt-*` ID (unlisted ones forward raw; `-fast` = priority tier)      |
| Kimi           | A Kimi account with Kimi Code access   | `k3`/`kimi-k3` (legacy `kimi-for-coding`); unlisted `kimi-*` forward raw |
| Grok           | grok.com                               | `grok-*` IDs (unlisted ones forward raw)                                 |
| Antigravity    | Google account with Antigravity access | `antigravity/<id>`; `cc-proxy models list antigravity` lists models      |
| OpenCode Go    | OpenCode Go subscription               | Non-conflicting IDs and `opencode-go/<model-id>`                         |
| Cursor Agent   | Cursor account                         | Cursor aliases and `cursor:<model-id>` prefixes                          |
| GLM            | z.ai API key                           | `glm-*` IDs (unlisted ones forward raw)                                  |
| GitHub Copilot | GitHub account with a Copilot plan     | `copilot/<id>`; `cc-proxy models list` lists yours                       |

Run `cc-proxy models list` for the current catalog or
`cc-proxy models list --full` for every dynamic Cursor alias.

> [!WARNING]
> The proxy accepts local requests without client authentication. It binds to
> `127.0.0.1` by default. Protect any non-loopback listener with a firewall or
> authenticating reverse proxy. Provider subscriptions, model access, terms,
> and account enforcement remain under each provider's control. Unofficial
> clients may carry account risk.
